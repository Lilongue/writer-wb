## 3 марта 2026 г

* **Реализация Drag-and-Drop для повествования:** Реализована функция для реорганизации элементов в дереве повествования с помощью перетаскивания (drag-and-drop). Ключевой особенностью является механизм "интеллектуальной коррекции" некорректных перемещений, названный "Контекстное Погружение" (Contextual Dive). Если пользователь пытается переместить элемент в невалидную позицию (например, дочерний элемент с меньшим "весом" в родительский с большим), система не просто отменяет действие, а ищет наиболее подходящее валидное место. Алгоритм поднимается вверх по иерархии от места сброса, находит первого подходящего "предка-контейнера", а затем спускается по цепочке его "первенцев", чтобы найти самое глубокое допустимое место для вставки. Это решает как проблемы невалидных вложений, так и причуды UI-библиотеки, которая может неверно сообщать тип сброса ('after' вместо 'inside').
