# План работ на спринт v0.2.4

**Общая трудоемкость:** 17 дней.

Этот план сфокусирован на решении технического долга, укреплении архитектуры и исправлении багов для повышения стабильности и качества кодовой базы.

---

1. **Полное тестовое покрытие бэкенда**
    * **Описание:** Написать unit-тесты для всех сервисов, DAO и утилит в `src/main`, обеспечив не менее 80% покрытия кода.
    * **Оценка:** 5 дней

2. ✅ **Потеря данных при закрытии/архивации проекта**
    * **Описание:** Исправить баг, при котором несохраненные изменения в текущем объекте теряются при закрытии или архивации проекта.
    * **Оценка:** 1 день

3. **Миграция проекта на новую версию**
    * **Описание:** Реализовать механизм для автоматического обновления структуры проекта при переходе на новые версии приложения.
    * **Оценка:** 3 дня

4. **Разделение системного и отображаемого имени для типов**
    * **Описание:** Разделить поле `name` в `entity_templates` на `system_name` (неизменяемое) и `display_name` (редактируемое), чтобы сделать переименование шаблонов безопасным.
    * **Оценка:** 1 день

5. **Рефакторинг main.ts**
    * **Описание:** Разбить `main.ts` на несколько более мелких и сфокусированных модулей (например, `ipcHandlers.ts`, `windowManager.ts`) для улучшения читаемости и поддерживаемости кода.
    * **Оценка:** 2 дня

6. **Централизованное управление таймерами опроса**
    * **Описание:** Создать единый `PollingService` в `renderer`-процессе для централизованного управления опросом файловой системы, устранения дублирования кода и предотвращения утечек таймеров.
    * **Оценка:** 1 день

7. ✅ **Раздражающие уведомления при редактировании во внешнем редакторе**
    * **Описание:** Улучшить механизм уведомлений, чтобы избежать спама при частом сохранении файлов во внешнем редакторе.
    * **Оценка:** 1 день

8. **Контекстное меню не скрывается при открытии модального окна**
    * **Описание:** Исправить UI-баг, при котором контекстные меню остаются видимыми поверх модальных окон.
    * **Оценка:** 1 день

9. ✅ **Лишняя приписка имени проекта к имени шаблона при экспорте**
    * **Описание:** Удалить префикс имени проекта из имени шаблона при экспорте World Objects, так как он стал избыточным после внедрения механизма обнаружения конфликтов.
    * **Оценка:** 1 день

10. **Унификация отображения списков**
    * **Описание:** Привести внешний вид списков (дополнительные файлы, план повествования, связи) к единому стандарту, чтобы в свернутом состоянии они выглядели одинаково.
    * **Оценка:** 1 день
