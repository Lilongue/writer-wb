# Декомпозиция функционала и определение MVP

Этот документ содержит подробный перечень функционала, разделенный по модулям. Каждая фича помечена статусом ее включения в приложение.

**Обозначения:**

- ✅ **Реализовано.** Функционал, который уже есть в приложении.
- ❌ **Не реализовано.** Функционал, который будет добавлен в будущих версиях.
- ⚙️ **Взято в работу.** Функционал, который будет реализован в одной из следующих версий.
- ➖ **Разработка отменена.** Функционал, который после проработки признан не реализуемым или не нужным

|   ❌   | **Конфигурация подключения к Ollama (LLM Backend)** | Разработка пользовательского интерфейса в настройках приложения для конфигурирования подключения к локально запущенному серверу Ollama. |   ❌   | **Подбор синонимов**                  | Для выделенного слова выводит несколько вариантов синонимов как подсказку. Работает через Ollama (локальный LLM). Без автозамены.                                                                                  |
|   ❌   | **Проверка текста (стилистика)**      | Отправка выделенного фрагмента в LLM для анализа. Результат выводится как список рекомендаций в панели помощника. Результаты хранятся в БД с привязкой к файлу (несколько последних проверок).                     |
|   ❌   | **Проверка консистентности мира**     | Анализ связей повествование↔объекты мира. Без LLM: детектит фрагменты без связей и объекты-орфаны. С LLM: выявляет противоречия между описанием объекта и текстом. Warnings можно принять/скрыть.                  |
|   ❌   | **Генерация плана по основной мысли** | Кнопка рядом с добавлением пункта плана. LLM генерирует план на основе поля "Основная мысль" выбранного элемента. Результат в панели помощника, с опцией импорта (с предупреждением о замене существующего плана). |
|   ❌   | **Интеграция с внешними диалоговыми системами (Lore API)** | Реализация легковесного API (например, на базе MCP или HTTP API) для предоставления структурированной информации об объектах мира (World Objects) и их связях внешним AI-диалоговым системам или другим инструментам. Это позволит сторонним системам "вести диалог" в рамках заданного лора, используя актуальные данные проекта. Требует проработки механизма авторизации/доступа. |
