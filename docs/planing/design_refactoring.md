# План рефакторинга дизайна

## Стратегические цели дизайна

- **Лаконичность:** Интерфейс должен быть чистым, без визуального шума и отвлекающих элементов.
- **Простота:** Функциональность должна быть интуитивно понятной.
- **Низкий порог входа:** Новый пользователь должен иметь возможность быстро освоиться в приложении.

## Общие проблемы, требующие внимания

- **Неконсистентные отступы:** Различные отступы между элементами в разных частях приложения. Необходимо стремиться к единой системе отступов.
- **Смешанный язык интерфейса:** Наличие как русских, так и английских надписей. Необходимо привести все к единому языку (вероятно, русскому).

## 4. ✅ Переработать отображение и функциональность чек-листа для элементов повествования

**Цель:** Сделать назначение чек-листа интуитивно понятным и улучшить его функциональность.

**Проблема:**
Текущая реализация с использованием чекбоксов неочевидна. Пользователи (и даже дизайнеры) не понимают, что чекбокс означает "выполненный пункт плана", а не включение/выключение элемента.

**Предлагаемые изменения:**

1. **Заменить чекбоксы на статусы:**
    - Вместо чекбокса использовать текстовые статусы с цветовой кодировкой для обозначения состояния пункта плана.
    - **"План"** (серый цвет) - состояние по умолчанию для новых пунктов.
    - **"В работе"** (синий цвет) - новый статус, для пунктов, которые находятся в процессе выполнения.
    - **"Сделано"** (зеленый цвет) - для завершенных пунктов.
    - По клику на статус должно происходить его изменение в цикле: "План" -> "В работе" -> "Сделано" -> "План".

2. **Сделать блок плана сворачиваемым:**
    - Весь раздел с планом (чек-листом) должен быть обернут в сворачиваемую панель (например, `Collapse` от `antd`), чтобы пользователи могли скрыть его, если он не нужен, и разгрузить интерфейс.

**Компоненты для изменения:**

- `src/renderer/components/ContentDisplay/components/NarrativeDetails.tsx`: Отображение нового вида статусов и добавление сворачиваемой панели.
- `src/renderer/components/ChecklistEditor.tsx`: Изменение логики редактирования, чтобы она соответствовала новым статусам, а не булевому значению `checked`.
- `src/common/checklistUtils.ts`: Обновление вспомогательных функций для работы с новыми статусами.
- `src/common/types.ts`: Изменение типа данных для элемента чек-листа. Поле `checked` (boolean) должно быть заменено на `status` (string или enum со значениями 'plan', 'in_progress', 'done').
