# План на спринт v0.2.3

**Общие примерные трудозатраты:** 12.5 - 17.5 дней

**Задачи:**

1. ✅ **Реализация текстового представления связей (List View)**
    * **Описание:** В соответствии с новым дизайном, переработать существующий компонент отображения связей. Реализовать структурированное "табличное" представление, добавить переключатель видов ("Список"/"Схема") и фильтры по типам объектов. Задача включает в себя расширение модели данных на бэкенде для поддержки направления и типа связи.
    * **Пользовательская значимость:** Высокая.
    * **Примерные трудозатраты:** 2-3 дня.
2. ✅ **Синхронизировать панель "Дополнительные файлы" с файловой системой**
    * **Описание:** Панель "Дополнительные файлы" не обновляется автоматически, если пользователь добавляет или удаляет файлы в папке объекта напрямую через файловый менеджер. Необходимо реализовать механизм, который будет отслеживать такие изменения и обновлять список файлов в UI.
    * **Пользовательская значимость:** Высокая.
    * **Примерные трудозатраты:** 1-2 дня.
3. ✅ **Обработка дубликатов при импорте**
    * **Описание:** Система позволяет импортировать одни и те же данные несколько раз, создавая дубликаты шаблонов и объектов. Необходимо разработать механизм, который будет определять дубликаты при импорте, уведомлять пользователя и предлагать варианты решения (пропустить, перезаписать).
    * **Пользовательская значимость:** Высокая.
    * **Примерные трудозатраты:** 2-3 дня.
4. ✅ **Переработать дизайн поля выбора папки в настройках**
    * **Описание:** Текущий компонент для выбора пути к папке в настройках проекта выглядит громоздко и неэстетично. Необходимо улучшить его дизайн, чтобы он соответствовал общему стилю приложения.
    * **Пользовательская значимость:** Средняя.
    * **Примерные трудозатраты:** 1 день.
5. ✅ **Минимизировать количество уведомлений при операциях импорта/экспорта и архивации**
    * **Описание:** При выполнении фоновых операций, таких как импорт, экспорт или архивация, пользователь получает несколько промежуточных уведомлений. Следует сократить их до одного итогового сообщения: об успехе или ошибке.
    * **Пользовательская значимость:** Средняя.
    * **Примерные трудозатраты:** 1 день.
6. ✅ **Улучшить сообщение об ошибке при создании проекта в существующем проекте**
    * **Описание:** При попытке создать новый проект в папке, которая уже содержит проект, пользователю отображается технически избыточное сообщение об ошибке. Необходимо упростить это сообщение, оставив только понятную для пользователя часть.
    * **Пользовательская значимость:** Средняя.
    * **Примерные трудозатраты:** 0.5 дня.
7. **Реализация графа связей (Graph View)**
    * **Описание:** Реализовать отображение связей в виде интерактивного графа ("Схема"). Узлы в графе должны быть кликабельны для навигации. Добавить возможность фильтрации по типам объектов для управления сложностью отображения. Эта задача выполняется после реализации нового текстового представления и расширения модели данных.
    * **Пользовательская значимость:** Высокая.
    * **Примерные трудозатраты:** 3-4 дня.
8. ✅ **Обеспечить актуальность базы данных при архивации проекта**
    * **Описание:** При архивации проекта изменения, внесенные между открытием и архивацией, могут быть не сохранены в базе данных, что приводит к потере данных или неактуальному состоянию архива. Перед архивацией проекта необходимо убедиться, что все изменения из временной рабочей копии полностью сохранены в базе данных. Возможно, потребуется принудительная синхронизация или сохранение всех pending изменений.
    * **Пользовательская значимость:** Высокая.
    * **Примерные трудозатраты:** 1-2 дня.
9. ✅ **Перенос экспорта из меню "Файл" в "Данные"**
    * **Описание:** Функции экспорта логически относятся к управлению данными, а не к общим операциям с файлами. Изменить структуру меню, переместив пункты меню, связанные с экспортом, из подменю "Файл" в подменю "Данные".
    * **Пользовательская значимость:** Низкая.
    * **Примерные трудозатраты:** 0.5 дня.
10. ✅ Рефакторинг внешнего вида окна импорта World Objects
    * **Описание:** Внешний вид окна импорта World Objects деформируется из-за наличия чекбоксов. Необходимо провести рефакторинг окна, а также добавить механизм предупреждения о наличии совпадающих типов при импорте с опциями для разрешения конфликтов (пропустить, перезаписать, создать копию).
    * **Пользовательская значимость:** Средняя.
    * **Примерные трудозатраты:** 1-2 дня.
