# Дизайн-рефакторинг (UI/UX Замечания)

## ✅ 1. Некорректное удаление границ у полей ввода

* **Проблема:** Границы были удалены у всех полей ввода (`input`) в приложении.
* **Задача:** Удалить границы только у полей ввода в таблице со списком свойств выбранного объекта.
* **Анализ:**
  * Глобальное CSS правило, вероятно в `src/renderer/App.css`, слишком широкое.
  * Целевой компонент, скорее всего, `src/renderer/components/ContentDisplay/components/WorldObjectDetails.tsx`, который отвечает за отображение деталей объекта.
* **План исправления:**
    1. Найти и удалить глобальное правило, обнуляющее `border` у `input`.
    2. Создать новое, более специфичное правило, нацеленное на `input`'ы только внутри таблицы свойств в `WorldObjectDetails.tsx`.

## ✅ 2. Унификация отображения свойств объекта

* **Проблема:** Свойства объекта в разных частях интерфейса (модальные окна, панель деталей) отображаются по-разному.
* **Задача:** Унифицировать внешний вид и логику отображения свойств объекта.
* **Анализ:**
  * Отсутствует единый переиспользуемый компонент для рендеринга свойств.
  * Потенциальные места для рефакторинга: `WorldObjectDetails.tsx`, `WorldObjectModal.tsx` и другие.
* **План исправления:**
    1. Определить полный список UI-компонентов, где отображаются свойства объектов.
    2. Создать новый универсальный компонент (например, `ObjectPropertiesView.tsx`), отвечающий за отображение свойств. Он должен быть гибким для использования в разных контекстах (просмотр, редактирование).
    3. Провести рефакторинг, заменив текущие реализации на новый компонент.

## ✅ 3. Скрытие дополнительных полей в модальном окне создания объекта

* **Проблема:** Модальное окно создания объекта содержит избыточные поля, которые не нужны при первичном создании и могут смущать пользователя.
* **Задача:** Скрыть или сделать сворачиваемыми "дополнительные поля" в модальном окне создания/редактирования объекта.
* **Анализ:**
  * Компонент, скорее всего, `src/renderer/components/WorldObjectTree/components/WorldObjectModal.tsx`.
  * "Дополнительные поля" могут относиться к кастомным свойствам или метаданным.
* **План исправления:**
    1. Идентифицировать "дополнительные поля" в `WorldObjectModal.tsx`, которые не критичны для первичного создания.
    2. Внедрить сворачиваемый блок (например, `<details>` или кастомный компонент) для этих полей.
    3. Блок должен быть свернут по умолчанию при создании нового объекта.
    4. Убедиться, что эти поля доступны для редактирования после создания объекта.

## ✅ 4. Улучшение отступов и выравнивания в модальном окне создания проекта

* **Проблема:** В модальном окне создания проекта (`ProjectWizardModal.tsx`) отсутствует отступ сверху, а чекбоксы для выбора иерархических уровней располагаются неравномерно, особенно при переносе на несколько строк.
* **Задача:** Добавить отступ сверху и улучшить выравнивание чекбоксов.
* **Анализ:**
  * Целевой компонент: `src/renderer/components/ProjectWizardModal.tsx`.
  * Проблема вызвана отсутствием `padding` у тела модального окна и недостаточными стилями для компонента `Checkbox.Group`, который отображает уровни иерархии.
* **План исправления:**
    1. Добавить `padding-top` к основному контейнеру содержимого `ProjectWizardModal.tsx`, используя `bodyStyle` у компонента `Modal`.
    2. Применить стили к `Checkbox.Group` или его контейнеру, чтобы обеспечить равномерное расстояние между чекбоксами (например, используя `gap` со свойством `display: flex` и `flex-wrap: wrap`), что улучшит их читаемость и внешний вид при расположении в несколько строк.

## ✅ 5. Переработка модального окна импорта шаблонов

* **Проблема:** Текущий двухпанельный интерфейс в `ImportTemplatesModal.tsx` неинтуитивен.
* **Задача:** Заменить его на более наглядное представление в виде карточек с возможностью выбора и фильтрации.
* **Анализ:**
  * Требуется полный редизайн компонента `src/renderer/components/TemplateManager/components/ImportTemplatesModal.tsx`.
  * Задача включает в себя как рефакторинг макета, так и логики управления состоянием.
* **План исправления:**
    1. **Редизайн макета:** Заменить двухпанельную структуру на сетку/список карточек.
    2. **Компонент карточки:** Создать новый компонент `TemplateImportCard.tsx`, отображающий название шаблона, его поля и чекбокс для выбора.
    3. **Управление состоянием:** Внедрить в `ImportTemplatesModal.tsx` state для отслеживания выбранных шаблонов и текущего режима фильтрации.
    4. **Фильтрация:** Добавить переключатель "Все" / "Выбранные" для фильтрации отображаемых карточек.
    5. **Логика импорта:** Обновить обработчик импорта, чтобы он использовал список ID выбранных шаблонов.
