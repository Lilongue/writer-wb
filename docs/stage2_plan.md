# План реализации Этапа 2: Расширение редактора шаблонов

Этот документ описывает план работ по реализации второго этапа из `alpha_plan.md`.

## Ключевая идея

Вместо создания отдельных функций для добавления, удаления и редактирования каждого поля (что привело бы к множеству запросов к бэкенду), мы реализуем единый, атомарный механизм обновления всей схемы полей шаблона за один раз. Это более надежный и эффективный подход.

---

## Шаг 1: Бэкенд (Backend)

1. **`GenericDao.ts`**:
    * Добавить новый метод `updateTemplateSchema(id: number, schemaJson: string)`, который будет выполнять SQL-запрос `UPDATE entity_templates SET fields_schema = ? WHERE id = ?`.

2. **`TemplateService.ts`**:
    * Добавить новый основной метод `updateTemplateSchema(templateId, fields)`.
    * Этот метод будет принимать полный новый массив полей из фронтенда.
    * Он будет проходиться по массиву: существующим полям он сохранит их системное `name`, а для новых сгенерирует уникальное `name`.
    * Затем он вызовет `updateTemplateSchema` из DAO для сохранения всего обновленного JSON-объекта в базу данных.

3. **`main.ts`**:
    * Создать новый обработчик IPC `templates:updateSchema`, который будет вызывать соответствующий метод в `TemplateService`.

---

## Шаг 2: Фронтенд (Frontend) — `TemplateManagerModal.tsx`

1. **Добавить кнопку "Редактировать поля"** (`Edit Fields`) в список действий для каждого шаблона.
2. **Создать новое модальное окно** (или режим `edit-fields` в существующем) специально для редактирования полей.
3. **Реализовать логику модального окна:**
    * При открытии оно будет получать `fields_schema` из шаблона и заполнять им компонент `Form.List` от Ant Design.
    * Каждый элемент списка будет представлять собой поле и содержать два видимых инпута: **`Название поля (label)`** и **`Комментарий (comment)`**. Системное `name` будет храниться в состоянии формы, но скрыто от пользователя.
    * Пользователь сможет добавлять новые поля (с пустыми инпутами) и удалять существующие.
4. **Сохранение изменений:**
    * При нажатии "Сохранить" фронтенд соберет весь обновленный массив полей из формы.
    * Затем он отправит **один** IPC-вызов `templates:updateSchema` с `templateId` и этим новым массивом.
    * После успешного сохранения список шаблонов в главном окне обновится.
